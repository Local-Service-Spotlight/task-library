Who owns what

Every repository in the organization, grouped by the person with the most commits in it. Box width is proportional to commit count on the default branch, on one shared scale — so a box twice as wide had roughly twice the commits.

At a glance

Ownership

One row per person. Owner is whoever has the most commits in that repository — it is measured, not declared, unless a CODEOWNERS file says otherwise, in which case CODEOWNERS wins and the row is marked. A red dot means exactly one person has ever committed to that repository.

How the tree fits together

Left to right is the direction work flows: shared runtime, then the things built on it, then what the public actually sees.
