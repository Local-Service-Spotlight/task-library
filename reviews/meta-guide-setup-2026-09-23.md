## Correction and steps decision

The public page contained an older eight-step skill summary. It omitted first-use setup and actionable ledger validation that already existed in the maintained skill. The embedded block now matches the maintained skill text, excluding START/END wrapper and surrounding whitespace. No task-file or downloadable package instruction changed.

The new “Before your first work record” section says to open the guide, check approved inputs and the output folder, preserve the actual run ID and start time, record missing facts, validate the candidate through the maintained ledger process, and hand off the checked draft. It explicitly explains that saving a skill does not install a plugin, connect accounts, or schedule work. One-time work needs no schedule. Repeated work needs a configured trigger and saved state.

The reusable prompt now accepts running and blocked attempts and forbids an invented result or finish time. Four scorecard notes now use available tools and existing authority instead of assigning mechanical metadata/category work to a human by default. Missing media or permission remains an explicit dependency.

The steps criterion passes: trigger, prerequisites, setup, ordered actions, checks, expected output, completion limits and the receiving owner are present and consistent.
