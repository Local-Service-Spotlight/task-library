# Set up a Special Project workspace

**Use this when:** A relationship owner approves a scoped one-off Special Project.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/special-project/) before executing; it contains the detailed actions and current source-specific instructions.

## Inputs
- Named relationship and project purpose
- Owner and agreed scope
- Existing conversation and source context
- Authorized project access

## Steps
1. Name and classify the project correctly.
2. Set the overview and accountable lead.
3. Create the standard threads and role assignments.
4. Invite only the intended participants.
5. Verify the access checklist and next action.
