# Set up a business AI work environment

**Use this when:** A nontechnical owner wants to set up their first supported AI work environment.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/start/) before executing; it contains the detailed actions and current source-specific instructions.

## Inputs
- Supported computer and AI plan
- Chosen runtime’s current capabilities
- Authorized website access if connecting a site
- One useful first job

## Steps
1. Install the supported desktop runtime.
2. Enable its work mode.
3. Install the canonical skills.
4. Connect the website through the approved credential method.
5. Configure one first job and verify a real result.
