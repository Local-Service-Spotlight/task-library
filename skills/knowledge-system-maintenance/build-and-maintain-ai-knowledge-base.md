# Build and maintain an AI knowledge base

**Use this when:** A person or client needs one source-backed knowledge base for ongoing work.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/how-to-build-use-publish-ai-knowledge-base/) before executing; it contains the detailed actions and current source-specific instructions.

## Steps
1. Build the personal or client corpus.
2. Derive voice, topics, context and entity facts from evidence.
3. Read the base at session start and update it at wrap-up.
4. Publish only approved public-safe outputs from the base.

## Definition of done (QA checklist)

**Expected result:** A maintained knowledge base with traceable facts and a record of what each session shipped or learned.

- [ ] Raw sources remain distinct from compiled records
- [ ] Voice and entity facts trace to real material
- [ ] Session updates preserve current status and provenance
- [ ] Public outputs omit private files and metrics
- [ ] Record the exact source revision, actual result and evidence; retain failure, partial, blocked and unknown states.
