# Find a Real Reason to Say Thanks

People help your business in small ways each day. This guide helps you spot one good deed and say why it mattered. Start with a real event. Finish with a clear note that someone can use to record thanks.

**The path:** Real good deed → check the facts → one clear note.

**Use this when:** a real referral, useful lesson, kind act or completed piece of work gives you a specific reason to thank someone.

## Inputs

- The source of the good deed: a project note, message, call notes or your own dated recollection.
- The person’s name, their role in this event and the intended private or public use.
- The existing gratitude log, if there is one; no account access is needed merely to write the note.

## First-run prompt

> Use this source to find one specific reason for thanks. Name what the person did and why it helped. Check for a duplicate. Save a short recording note and flag facts or sharing rights we still need.

## Steps

1. Read the actual source. Write the event date and one sentence about what happened; distinguish an observed deed from a guess about someone’s motive.
2. Confirm the right person and spelling. If two people share the name, use the known project or profile to resolve identity rather than choosing the first search result.
3. State what they did, the practical effect and your genuine reason for thanks. Keep numbers and claims within the source; an introduction is not a sale unless that sale is proven.
4. Check the log for the same person, deed and date. Reuse an existing record when this is the same event; a new deed can deserve new thanks.
5. Choose the audience. Keep personal matters and private client details out of a public script. Note whether the event can be shared and whether the person wants to be named; a private thank-you can be the right outcome.
6. Write three short talking points: their name, the specific deed and why it mattered. Remove any pitch, request for a favor or implied endorsement of your business.
7. Save the source reference and talking points with a next owner. If a key fact is missing, mark exactly which fact needs checking and prepare the rest.

## Definition of done (QA checklist)

- [ ] One real, sourced deed is named without added results.
- [ ] Identity and duplicate check are recorded.
- [ ] Private details and intended sharing scope are clear.
- [ ] The note contains a specific reason for thanks and no request for a return favor.
- [ ] The next owner can find the source and the recording note.
