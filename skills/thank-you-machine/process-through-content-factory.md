# Process the Thank-You Clip

One thank-you clip can be used in more than one place. This guide helps your team make the files you need without changing the story. Start with the checked clip. Finish with clear files and a list of where each may go.

**The path:** Checked clip → useful versions → reviewed files and next owner.

**Use this when:** the original clip is checked and you know who should see it.

## Inputs

- The original clip, checked transcript and source note.
- The agreed channels, audience and sharing rights; planned formats must serve a real use.
- Access only to the file store and editing tools needed for the chosen outputs.

## First-run prompt

> Use this thank-you clip to make the agreed files. Keep the facts and tone. Fix captions, label each version and prepare the right post or private-message copy. Show which files are checked and what comes next.

## Steps

1. Open the original and source note; confirm that this is the checked take. Preserve the original rather than overwriting it.
2. Choose the needed outputs, such as the full clip, a short cut, captions or a brief text post. Do not force five formats if the audience only needs one.
3. Edit for clarity and remove dead space without changing the reason for thanks. Keep enough context for a stranger to understand the deed. Do not use an edit to make the recipient appear to endorse your business.
4. Correct names and words in the transcript, then time captions to the clip. Choose framing and text size for each agreed channel; verify current platform requirements when exporting.
5. Write a short caption naming the deed and why it mattered. Attribute any real quote accurately. A thank-you you recorded is not a customer testimonial; do not label it as their recommendation.
6. Review each export visually and inspect its duration, dimensions, file size and caption timing. Keep agent playback silent. Open the saved export, not only the editor preview.
7. Create an output list with file link, format, audience, permission limits, checked state and next owner. Prepare post drafts or the private-message draft. Publish or send only when that action is already authorized, and record its actual result separately.

## Definition of done (QA checklist)

- [ ] The original is preserved and each chosen export opens.
- [ ] Facts, names, attribution and tone match the source.
- [ ] Captions and visible text are readable for the intended channel.
- [ ] Every output has a purpose and sharing scope; no fabricated testimonial was created.
- [ ] Draft, exported, posted and delivered states are distinguished in the handoff.
