# Add homepage blog-card thumbnails

**Use this when:** An existing homepage article card lacks a relevant real thumbnail.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. ## Steps
1. Choose an existing featured image, real video frame, or real photo.
2. Inspect the card’s actual overflow and use the matching layout.
3. Preserve existing markup while adding the image.
4. Save through the working builder pipeline.
5. Verify the anonymous published result.
