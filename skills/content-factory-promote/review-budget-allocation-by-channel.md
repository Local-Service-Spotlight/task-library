# Review budget allocation by channel

Your ad money may be spread across several places. This guide helps you see what each one cost and what it did. Start with the goal and the real spend for the same time span.

**The path:** Matched spend → comparable results → bounded proposal → measured recheck.

**Use this when:** A campaign budget review is due or spending no longer appears aligned with the stated goal.

## Inputs
- Dated spend and result exports by channel/campaign with currency, attribution and result definitions.
- The actual total budget, commitments, targets and stage roles; margin/revenue evidence when return is part of the goal.
- Prior allocation decisions, current operator authority and any limits on changes, stops or new tests. Read access is enough to prepare the review.

## First-run prompt

> Reconcile spend and compare each line with its matching goal. Separate cost targets from return targets and preserve attribution limits. Propose a bounded before/after allocation, keeping uncommitted funds unspent unless their use is authorized. Execute only changes already in scope and record actual read-back.

## Steps
1. Build a table by channel and campaign with spend, result count, definition, matching cost or return, target and stage. Reconcile totals to source reports, avoiding double-counted campaign/ad-set subtotals.
2. Keep currencies and windows consistent. Do not add each platform’s attributed conversions as unique business sales without a supported reconciliation. Keep paid, organic and blended measures explicitly separate.
3. Compare like goals. For cost per acquisition, above the target is worse; for return on ad spend, below the target is worse. A cheap view is not a cheaper lead, and revenue divided by spend is not profit.
4. Check result quality, tracking and minimum evidence before labeling a winner. An ad at its budget limit is not automatically underfunded, and an expensive qualified sale can be more useful than cheap irrelevant leads.
5. Review stage coverage against the actual plan and eligible audiences. A full nurture program may need several jobs, but every account need not fund all stages or all platforms. A stage can remain unfunded when evidence, audience size or scope does not support it.
6. Create a before/after proposal with each change’s reason, amount, dates and recheck. Preserve the small-test method and ≤2× ceiling for any separate increases, without claiming platform learning is guaranteed safe. Consider the current $30 total/30-day continuation before assuming vertical increases.
7. Keep any research reserve tied to actual authority and proven-content rules. The old roughly-10% language is not permission to divert money into unproven ads. Stopped spend stays uncommitted unless a specific reallocation is covered.
8. Apply only authorized exact changes and read them back; otherwise deliver the proposal through the existing route. Record what really changed and the next measurement window so the following report can judge the decision.

## Definition of done (QA checklist)

- [ ] Spend totals reconcile without duplicate subtotals or mixed currencies.
- [ ] Cost and return goals use the correct direction and matched result type.
- [ ] Quality/attribution gaps prevent unsupported winner labels.
- [ ] The proposal fits real totals, stages, dates and change authority.
- [ ] Proposed, applied and observed effects are separately documented.

## Example(s)

**Fictional teaching example:** Two channels spend $100 each. A produces five qualified leads, or $20 per lead. B produces ten, or $10 per lead, against a $15 target. A’s source quality is checked before a stop is proposed. B is a candidate for a further bounded test, not proof that twice the spend will buy twice the leads. Separately, a sales campaign has a 4× return target but records 3×, so it misses the target even though the number is “below target.” Unspent money is not moved without the existing scope covering that change.
