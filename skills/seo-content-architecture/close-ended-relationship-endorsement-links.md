# Close endorsement links for an ended relationship

**Use this when:** The roster says Not Active or the relationship owner directly confirms that the endorsement relationship has ended.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/when-trust-ends-the-link-ends/) before executing; it contains the detailed actions and current source-specific instructions.

## Inputs
- Verified end-state instruction
- Controlled public pages and affected hosts/profile URLs
- Current endorsed alternatives
- Authority for any account-role removal

## Steps
1. Confirm the relationship ended.
2. Inventory the affected links you control.
3. Retain the history and change only the appropriate link or association.
4. Check role-removal boundaries.
5. Verify anonymous pages and record the closeout.
