# Publish an SEO Tree site directory

**Use this when:** A site needs a public directory showing its actual entity, topics, supporting content, and proof.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/seo-tree-site-directory/) before executing; it contains the detailed actions and current source-specific instructions.

## Inputs
- Site content inventory
- Verified entity identity and sources
- The existing canonical hubs and page URLs

## Prerequisite tasks
- [The Topic Wheel](https://blitzmetrics.com/topic-wheel/): If the brand’s topics have not yet been defined
## Input references
- [The SEO Tree Framework: How Every Piece of Content Should Connect](https://blitzmetrics.com/seo-tree/)
## Steps
1. Identify the trunk.
2. Define the topic branches.
3. Map existing content as leaves.
4. Verify the roots.
5. Build the visual diagram.
6. Publish the directory and use the tree test.

## Definition of done (QA checklist)

**Expected result:** A public /seo-tree/ directory with a linked visual map and plain-language explanation.

- [ ] Each branch has a canonical hub
- [ ] Leaves connect to their real branch
- [ ] Roots distinguish verified evidence from missing evidence
- [ ] The directory and its links are publicly readable
