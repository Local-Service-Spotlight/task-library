# Manage a group member website request

**Use this when:** A group member submits a request for a personal-brand website.

This is a registered recipe in review. A published guide or this new record does not certify its runtime behavior. Read the current [canonical procedure](https://blitzmetrics.com/group-website-request-intake/) before executing; it contains the detailed actions and current source-specific instructions.

## Inputs
- Intake record identifying member and group
- Actual domain and DNS owner
- Known source assets and site goal
- A verified conversation and status record

## Steps
1. Capture the request in the shared intake.
2. Check domain, assets and goal.
3. Build and review the site.
4. Prepare the exact DNS action while preserving email.
5. Verify live status and return the result to the same conversation.
