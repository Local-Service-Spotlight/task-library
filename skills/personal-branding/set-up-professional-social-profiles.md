# Set up professional social profiles

Help people find the real you on the sites they use. This guide checks your work profiles and connects them to your own site. Start with the accounts you already control before you make new ones.

**The path:** Existing accounts → Right identity and ownership → Approved profile setup → Verified URL list

**Start when:** The person needs a checked set of agreed public profiles or corrections to existing ones.

## Inputs

- [Build the personal brand site](https://local-service-spotlight.github.io/task-library/?task=build-personal-brand-website#task-build-personal-brand-website) with the accepted home URL, public name and real identity facts.
- The agreed platform list based on actual audience needs and the person’s existing accounts.
- Actual account owner, supported delegated roles, setup authority and secure recovery/access record.

## Steps

1. Inventory current profiles, handles and account owners before creating anything. Separate wrong-person matches, abandoned accounts and potential duplicates. A duplicate-looking result needs an ownership check; it is not permission to delete an account or assume a claim right.
2. Choose the platforms relevant to the person’s work. The source’s LinkedIn, Facebook, Instagram, YouTube and X list is a planning starting point, not a universal requirement to open all five. Record the agreed scope and why a platform is excluded or pending.
3. Use a clear handle and the accepted professional name within each platform’s actual rules. Preserve a legitimate existing handle when change would break useful links without a reviewed reason. Do not imply that matching every handle guarantees one search identity.
4. Use the actual supported account/profile type for the intended person or business. Check current platform setup documentation and the live controls before creating, converting or connecting accounts. A personal profile and a company page serve different entities and should not be silently merged.
5. Keep ownership and recovery with the person or the appropriate business owner, and use supported delegated roles for helpers. Complete verification with the account owner where required; a skill or connected browser does not confer new account-creation, transfer or publication authority.
6. Add the verified home URL where the platform permits and prepare the approved bio/photo fields. Use [Align photos and bio facts](https://local-service-spotlight.github.io/task-library/?task=add-consistent-headshots-and-bios-across-profiles#task-add-consistent-headshots-and-bios-across-profiles) for consistent current facts. Do not leave misleading blank or placeholder profiles public solely to finish a count.
7. After authorized setup, open the actual public profiles, check identity and destination and save their exact URLs. Keep blocked access, pending verification and unavailable link fields explicit. Only the accepted same-person profile list passes to schema work.
