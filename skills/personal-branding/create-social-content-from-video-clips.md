# Create social content from video clips

Make short clips from your real videos. This guide turns a real source into short clips and clear post drafts. Start with the best complete answer and the people it should help.

**The path:** Checked source → Complete short clip → Platform post draft → Release and results

**Start when:** A usable video source needs short social versions for selected channels.

## Inputs

- [Record real customer answers](https://local-service-spotlight.github.io/task-library/?task=record-one-minute-videos-answering-customer-questions#task-record-one-minute-videos-answering-customer-questions) or another permitted source with speaker, date, transcript and exact file.
- The agreed channels, audience, main point, destination and source rights.
- Actual editing tool, caption process, current platform limits and release owner.

## Steps

1. Read the source and pick a complete idea that works without misleading cuts. Use the source’s roughly 15–60 second range as an editing target when it suits the story and placement. Preserve necessary context; split or lengthen a point that cannot be honestly shortened.
2. Cut from the real file and keep speaker, facts and sequence accurate. Do not manufacture a quote from unrelated fragments. Retain the source timestamp range and transcript so another reviewer can compare the clip with the original.
3. Add accurate captions, checking names and numbers manually against the source. Preview the face, key action, text and caption safe areas at the intended size. Review media silently with mute and volume zero; use transcript or measurements for audio checks if listening is not authorized.
4. Write each post for its actual audience and channel. Lead with the useful point, use a truthful hook and explain unfamiliar terms. A channel may need a different length or title, but do not rewrite merely to force different wording where the same message fits.
5. Choose the relevant owned destination using [entity linking, choosing the right home for a named person or topic](https://blitzmetrics.com/entity-linking/). Use a clickable post link where supported or the correct profile route where it is not. Credit or tag verified participants only when relevant and consistent with the release scope.
6. Prepare the complete media, copy and destination for review. Publish only on the channels authorized, using their supported controls. Open each actual public post after release and check the source, captions, crop and route; record unavailable or pending surfaces honestly.
7. Save the exact asset/post IDs and later date-bounded metrics in the existing content record. Keep planned, exported, posted and measured states separate. Pass comparable results to the creative-selection task rather than assuming a posted clip is a winner.

## Definition of done (QA checklist)

Quality assurance (QA) means checking the actual result against its agreed requirements. Follow the [Article Guidelines](https://localservicespotlight.com/article-guidelines/).

- [ ] Every clip carries a complete source-backed point and an exact source range.
- [ ] The actual platform preview, captions, credits and useful next route are checked.
- [ ] Only observed posts are labeled live and their later metrics retain source and period.
- [ ] The exact output, source revision, reviewer evidence and remaining owner action are saved.
- [ ] For any reader-facing output, the short grade-five opening states the reader’s useful outcome and supporting method or proof. The body delivers that promise; a useful authentic visual appears in the first screen. Retain exact text and quoted reviewer evidence.
