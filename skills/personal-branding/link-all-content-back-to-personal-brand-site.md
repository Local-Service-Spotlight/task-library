# Link all content back to personal brand site

Help readers reach the right next page from your work. This guide checks links in posts, profiles and guest features. Start with your live content list and the site that should be your public home.

**The path:** Asset list → Right destination → Owned edits or host request → Checked path

**Start when:** A bounded set of published assets needs its identity and topic links checked.

## Inputs

- The current content inventory with exact URLs, platform and edit owner.
- Verified person/company sites and relevant topic/offer pages; [entity linking, choosing the right home for a named person or topic](https://blitzmetrics.com/entity-linking/) and the [SEO Tree, the map from proof pages to main topics and offers](https://blitzmetrics.com/seo-tree/).
- Actual edit/send authority and the previous link audit, if one exists.

## Steps

1. Set the scope from the existing inventory and add newly discovered assets there. Record URL, publisher, article purpose, current destination and edit owner. A known list is a bounded audit scope, not proof that every asset on the web has been found.
2. Choose the useful destination for each first mention. The person’s name points to their verified home, a company to its own site, and a method to its maintained guide. A source citation or required tool action keeps its direct source rather than being replaced with an irrelevant internal page.
3. Use meaningful anchor text that identifies the person or destination naturally. The house three-to-six-word preference is a guide, not permission to pad a two-word person’s name or change the sentence’s meaning. Do not repeatedly link the same entity in one piece.
4. On the owned site, check a real path from each supporting page to its topic and relevant offer under the SEO Tree. Add a useful parent link and related proof where appropriate. Avoid forcing every article directly to the homepage when a more specific branch serves the reader.
5. On social pages, use the supported website field or relevant post link. If a channel makes links non-clickable, record the actual profile or other supported path and test it. Do not claim every post contains a clickable link when the platform does not provide one.
6. For a third-party feature, prepare a specific factual credit/link request to its actual editor under send authority. Keep pending, declined and accepted outcomes separate. The host controls its editorial links; a refused link does not erase a real mention.
7. After authorized changes, follow each repaired path from the normal public asset to the intended page. Save exact URLs, source revision, results and remaining owner actions. Review newly released or changed content through this same bounded method; recurring timing needs an actual owner.

## Definition of done (QA checklist)

Quality assurance (QA) means checking the actual result against its agreed requirements. Follow the [Article Guidelines](https://localservicespotlight.com/article-guidelines/).

- [ ] Each in-scope asset has a checked useful path or a specific supported limitation and next owner.
- [ ] Identity links, topic hierarchy and primary citations retain their correct purposes.
- [ ] Repaired links are publicly read back; outside requests are not counted as accepted edits.
- [ ] The exact output, source revision, reviewer evidence and remaining owner action are saved.
- [ ] For any reader-facing output, the short grade-five opening states the reader’s useful outcome and supporting method or proof. The body delivers that promise; a useful authentic visual appears in the first screen. Retain exact text and quoted reviewer evidence.
