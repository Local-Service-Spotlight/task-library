# Stage 6: Optimization (metrics, budget review, recommendations)

Use the latest results to choose the next useful change. This guide helps your team see which part needs work and who should fix it. Start with this period’s facts, the original goal and the last action list.

**The path:** Results + prior actions → Explain the change → Bounded plan → Next cycle

**Start when:** The agreed engine review is due and there is sufficient data to inspect, or a source gap needs routing.

## Inputs

- [Actual campaign settings and result records](https://local-service-spotlight.github.io/task-library/?task=stage-5-amplification-boost-posts-remarketing-ads#task-stage-5-amplification-boost-posts-remarketing-ads).
- [The accepted goals/economics brief](https://local-service-spotlight.github.io/task-library/?task=stage-2-goals-mission-90-day-goals-cpa-roas-budget#task-stage-2-goals-mission-90-day-goals-cpa-roas-budget) and prior actions.
- Matching source exports, conversion definitions, dates, tracking limits and action authority.

## Steps

1. Read back which prior actions actually happened, their timing and any concurrent account changes. Start comparison from the real state, not the prior report’s intentions.
2. Break a headline result into useful components. With the same clicks and conversions, cost per lead equals average cost per click divided by leads per click. Check matching populations and zero denominators before applying the formula.
3. Compare the current and prior comparable periods, allowing for conversion lag, seasonality, mix and changed definitions. Name observed changes and plausible explanations separately; do not assign a proven cause to every fluctuation.
4. Audit actual spend against the agreed total and by relevant campaign, audience or channel. Pair unit cost with qualified volume and business outcomes so a cheap result is not mistaken for a good one.
5. Choose the highest-value concrete next actions, usually a small set for the coming week. Each has an evidence link, owner, due date, expected signal and decision rule. Fewer supported actions are better than padding to three or five.
6. Route new content to phase 3, audience work to phase 4, and approved campaign changes to phase 5. Keep proposals separate from execution and check any authorized change afterward.
7. Save the [Metrics, Analysis, Action: what happened, why and what to do](https://blitzmetrics.com/maa/) report and handoff. The next agreed cycle checks these results; no guide text creates a weekly job or guarantees that a provider will run it.
