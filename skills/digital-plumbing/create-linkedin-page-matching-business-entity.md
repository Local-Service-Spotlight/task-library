# Create LinkedIn Page Matching Business Entity

Does your business have a clear home on LinkedIn? This guide helps an owner set up or fix the right Page. Start by finding any Page that already stands for the business.

**The path:** Find business Page → Confirm role → Edit facts → Read back.

**Use this when:** the business needs a LinkedIn Page or its current Page contains old or conflicting identity information.

## Inputs
- The business identity record, website, existing Page URLs and approved logo and cover image.
- An individual member account with the required Page role; for full Page-field editing, confirm super-admin access.
- The real organization type, industry, size and current public description. No false employment changes or invented affiliations.

## First-run prompt

> Find the correct existing company Page. Verify the actual role and update authorized identity fields, or create a Page only if no appropriate one exists. Keep access requests, employee profiles and public Page content distinct.

## Steps
1. Identify existing Company, Showcase or Listing Pages using the supplied business facts. A valid product or branch Page is not automatically a duplicate. Record the Page URL and type before choosing the source to update.
2. Open Page admin view through the legitimate individual member account. LinkedIn Pages have assigned roles, not a separate shared Page password. Confirm the role supports the intended action; a content role is not a substitute for every super-admin setting.
3. For an existing Page, use its supported access or claim process when needed. Do not add a false job to a person’s profile to obtain access. If a real authorized person must complete a workplace or account check, state that precise dependency.
4. If no appropriate Page exists, use For Business → Create a Company Page on the supported interface. Select the real type, enter the business details and attest to authority only when it is true. Record the resulting Page and its business-controlled super admin.
5. Set the supported public name, website, industry, size and available handle from the identity record. Explain what the company does in a concise About section; company voice can use “we,” while individual experience belongs to the individual.
6. Upload the approved logo and cover, then check their crop and text on phone and desktop. Use real rights-cleared evidence and avoid overstating customer, partner or employee relationships.
7. Review employee affiliations as an evidence check, not an instruction to change others’ accounts. If an actual employee needs to update a profile, give that person the correct Page URL through the job’s existing handoff; do not fabricate employment or send unrequested invitations.
8. Read back the public Page and website link. Save the final Page ID or URL, verified fields and role state. Update the business entity’s profile reference in the appropriate source if that change is in scope; do not put the company Page into a personal sameAs list.

## Definition of done (QA checklist)

- [ ] The chosen Page represents the correct company and preserves valid related Pages.
- [ ] The actual operator role and business-controlled owner are recorded without shared credentials.
- [ ] Public facts, description, logo, cover and website link are correct.
- [ ] No employee relationship or Page-control claim exceeds its evidence.
- [ ] Pending access and unrequested profile changes remain distinct from completed branding edits.

## Example(s)

**Fictional teaching example.** Oak Repair has a main Company Page and a separate training Showcase Page. The main Page’s website is outdated. A verified super admin changes that website and the cover crop, then records two matching read-backs. The Showcase Page stays. A contractor’s personal profile is not changed to say “employee” just to make access easier. This teaches a clean company record without inventing relationships.
