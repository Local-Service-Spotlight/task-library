# Step 14b: Run LinkWhisper for internal links

A link tool can suggest pages, but it cannot choose your story for you. This guide helps you pick links that make sense. Start with the page’s main topic, then read each suggested target before you add it.

**The path:** Topic map → Review suggestions → Scoped link edits → Saved link checks.

**Use this when:** A prepared article needs useful outgoing and incoming links, and the site uses Link Whisper.

## Inputs
- The exact article and current [SEO Tree](https://blitzmetrics.com/seo-tree/) map, plus the [entity-linking guide](https://blitzmetrics.com/entity-linking/) for choosing owned and identity destinations.
- A working Link Whisper installation, license/features where required, and current link data. Link Whisper is a WordPress add-on that suggests and adds links. Check that its installed version supports the editor and content type.
- Authority and access to change this article and any older pages chosen for incoming links.
- The page’s publication state, current revision and a place to record each source sentence, anchor, target and result.

## First-run prompt

> Review Link Whisper suggestions for the exact article and page map I provide. Read targets and choose useful links; apply only scoped edits. Check older source pages before adding incoming links. Do not enable auto-linking or paid AI by default. Report inserted links separately from suggestions and staged edits.

## Steps
1. Open the existing Link Whisper setup and confirm it is ready for this post type. Verify that its content scan includes the current article revision; run the approved scoped scan or name the setup owner when data is stale or setup is missing. Do not accept launch-wizard defaults blindly: current options may create automatic linking rules.
2. Read the article’s outgoing suggestions. These point from the article to other pages. Open each candidate and compare it with the sentence’s meaning and the main topic owner.
3. Choose a small set of helpful links. Point method mentions to their maintained owned guide; use accurate identity destinations and precise primary proof where needed. Reject irrelevant, duplicate, misleading or competing-hub suggestions.
4. Edit anchors into clear words that describe the target. Follow the maintained house guidance of roughly three to six descriptive words where it fits, without changing the sentence’s meaning to hit a word count.
5. Apply only the reviewed outgoing links through the supported editor/plugin control. Save and check that the expected sentences and URLs survived. If the editor/builder is unsupported, route a manual source-aware linking task and do not claim the plugin succeeded.
6. Review incoming suggestions, which would add a link on an older page pointing here. Confirm each older page is in scope and that the final target will be accessible to its readers. Avoid publishing a public link to a private draft.
7. Apply the specific authorized incoming edits and verify the changed source pages. Record any separate owner’s pending action. Do not turn a single-page link pass into cross-site connection, autolinking, paid AI processing, or a global search-and-replace.
8. Check every added URL and named fragment, first in the saved content and then in the served body when published. Update the inventory with actual outgoing/incoming paths and any pending work. Suggestions or map lines are not proof that links were inserted.

## Definition of done (QA checklist)

- [ ] The plugin setup, scan freshness and supported source are known; a missing/stale setup has a named owner and optional automation has not been silently enabled.
- [ ] Every accepted suggestion has a source sentence, meaningful anchor and verified target.
- [ ] The page has the required relevant upward/incoming paths, or exact unresolved edits are recorded.
- [ ] Changes to older pages stayed in scope and do not expose a private draft link.
- [ ] Saved and served links are verified as applicable, with no unsupported ranking or zero-orphan guarantee.

## Example(s)

**Fictional teaching example — no plugin was run.** A sample quote article gets three suggested destinations:

| Suggested anchor | Destination | Decision |
| --- | --- | --- |
| how our quotes work | Main repair-quotes guide | Accept; it explains the current sentence |
| our clear process | Unrelated tire-sale page | Reject; the shared word “process” is not enough |
| before your shop visit | Visit-planning guide | Accept after reading the guide |

An incoming suggestion would link an older guide to the new article, which is still a private draft. The publisher stages that sentence and adds it when the target is public under the actual job scope. “Two outgoing saved; incoming staged” is the truthful result.
