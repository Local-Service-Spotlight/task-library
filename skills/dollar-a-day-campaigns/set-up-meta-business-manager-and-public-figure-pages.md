# Set up Meta Business Manager and Public Figure pages

Your page and ad tools should stay under the right owner’s control. This guide helps you check what exists and fill the real gaps. Start with the person or business the page is meant to show.

**The path:** Real identity → existing assets → correct access → checked setup.

**Use this when:** A personal brand needs the Meta assets for an authorized campaign, or an existing setup’s ownership/access is unclear.

## Inputs
- The actual person/business identity, authorized owner and existing portfolio, Page, Instagram and ad-account records.
- An authenticated owner or authorized administrator with the required roles; recovery contact through the official route if access is missing.
- Approved name, headshot, bio, source posts and site link; the exact scope for setup, connections, publishing or billing changes.

## First-run prompt

> Inspect the existing Meta assets for this person or business. Map ownership and roles, reuse valid assets, and make only the setup changes already authorized. Do not ask for shared login credentials or use a paid boost as automatic setup proof. Return checked IDs, access scope and the smallest unresolved gap.

## Steps
1. Identify whether the page represents the person or the company. Keep real names, headshot/logo, bio and website consistent with that entity. Do not imply a personal Page is the company or create an unnecessary duplicate to satisfy the historical task title.
2. Inventory the existing business portfolio, Pages, Instagram identities, ad accounts and event data sources. Record ownership separately from assigned task access. A visible asset does not prove the operator can manage every setting.
3. Use the owner’s existing portfolio where appropriate. If setup or access is missing, use the supported invitation or recovery process with the current authorized administrator. Do not request the owner’s password or bypass account verification.
4. Assign only the roles required for the actual job when those grants are authorized. Preserve business control while allowing agreed agency/partner access. Document who can edit, view reports or spend without publishing private identifiers in a public article.
5. Create or update a person’s Page only when the plan needs it and the action is authorized. Choose an accurate available category; Public Figure is a descriptive choice, not a universal prerequisite for all Meta ads. Review the approved bio, real image and useful source posts.
6. Connect the specific Page, Instagram identity, ad account or event source that the campaign needs using the supported interface. Domain verification and pixel connections apply when required by the chosen features, not as a reason to install every integration.
7. Read back the ownership/role and connection settings, then inspect the public identity and existing content with media silent. Keep seeded draft content separate from actually published posts. A setup check does not need an automatic paid test boost.
8. Save an access map with checked date, role scope, unresolved step and next owner. If a paid test is already separately in scope, hand it to the campaign task with its own budget and dates; setup completion alone does not prove delivery or attribution.

## Definition of done (QA checklist)

- [ ] The real person/company identity and existing assets are correctly mapped.
- [ ] Ownership, assigned roles and permissions are distinct and supported.
- [ ] Only needed, authorized connections or grants were made.
- [ ] Public identity and saved setup were checked without unscoped media or spend.
- [ ] Campaign delivery is a separate next task; access gaps are not concealed.

## Example(s)

**Fictional teaching example:** A bike shop owner already has a personal-brand Page and a business ad account. The operator can view reports but cannot edit the Page bio. The map records that exact gap and names the current Page administrator as the route for the approved edit. No second Page is created and no password is requested. A separate company Page remains a separate entity. The setup report is complete as an inspection even though the bio change is pending; it does not invent a delivered $1 boost.
