# Set up TikTok campaigns

You have a useful clip and want to test it on TikTok. The test may cost more than one dollar a day. This guide helps you check the real price and decide if it fits your plan.

**The path:** Proven clip → actual minimum → bounded test → useful result.

**Use this when:** A proven video fits TikTok’s audience and the owner wants a bounded paid test at the platform’s actual cost.

## Inputs
- The eligible TikTok Ads account, authorized identity and roles; actual billing currency, allowed budget and dates.
- A proven video with commercial music/footage rights, readable captions and an appropriate destination.
- Goal, target and required event measurement; exact current campaign/ad-group settings and minimums.

## First-run prompt

> Prepare a TikTok test from this approved clip and goal. Read the current minimum budgets and state the full real cost. If it exceeds the authorized amount, return that gap rather than launching. Keep account setup, creative approval, delivery and result evidence separate.

## Steps
1. Use the owned Dollar-a-Day discipline: proven useful content first, then a bounded test. A winner from another platform is a candidate, not proof it will perform the same on TikTok.
2. Confirm the actual ad account, identity and content permission. Review rights for commercial use, including music; do not assume a song allowed in an organic post is cleared for an ad.
3. Write the goal and metric, then choose the eligible objective and measurement route. A website conversion goal needs its actual event path checked; an on-platform view goal does not automatically require a website pixel.
4. Prepare the video for the chosen format with a clear opening, useful lesson, fitting next step and captions. Check placement crops with media muted. Native style can be a creative approach; raw footage is not guaranteed to outperform edited work.
5. Read the current budget rules before building a matrix. TikTok’s official guide states daily budgets must exceed $50 at campaign level and $20 at ad-group level; lifetime rules differ. Confirm the controls used by this actual campaign and quote the real commitment, not a renamed “dollar.”
6. Select supported audience settings tied to the actual market and goal. Record constraints, suggestions and eligibility instead of copying every age/interest layer from Meta. Use fewer tests if the permitted budget and review capacity require it.
7. If authorized and feasible, set the real budget, dates and creative, then read back the saved state and early delivery. If the minimum does not fit, leave the paid test pending and retain the organic candidate. Do not switch budget type or expand scope just to make launch pass.
8. At the due review, compare the matching cost, view/watch metrics and useful response with the goal. Send stop, hold or further-test decisions to the campaign owner. Any later increase is a separately checked change; ≤2× is not a promise about TikTok learning behavior.

## Definition of done (QA checklist)

- [ ] Creative rights, identity and cross-platform evidence limits are recorded.
- [ ] The actual objective and necessary measurement match the goal.
- [ ] Minimums, budget type, full amount and dates are explicit.
- [ ] Infeasible spend stays pending without an automatic increase.
- [ ] Saved settings, delivery and performance verdict have distinct evidence.

## Example(s)

**Fictional teaching example:** A shop has only $21 authorized for all testing this week. Its seat-fix clip is a good organic candidate, but the chosen TikTok ad setup requires a daily amount above $20 at the ad-group level. A seven-day paid plan cannot fit $21. The planner records the exact mismatch and keeps the TikTok paid step pending; no new card is added and no budget is raised. The same clip may still be reviewed for an existing organic posting plan. This is a completed feasibility check, not a completed ad campaign.
